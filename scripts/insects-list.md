# 昆虫テーマ 素材生成リスト

保育園児向けぬりえ・昆虫カテゴリの生成計画。

## 共通仕様

- **命名**: `{item}-{unit}-{連番}`  例: `butterfly-rich-1`
- **Unit 展開** (4段階固定):
  - `simple` … アイテム1匹・背景なし（2〜3歳）
  - `easy` … アイテム＋1要素（3歳）
  - `normal` … ミニシーン（3〜4歳）
  - `rich` … にぎやかな自然シーン（4〜6歳）
- **共通条件に追加**: 「保育園児が楽しめる、かわいくシンプルな線画」

## 凡例

- ✅ 既存（data.ts に入り済み）
- 🆕 新規生成
